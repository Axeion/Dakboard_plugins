# Dakboard Plugins/Widgets

Here are some widgets and plugins for dakboard that I use to keep my life organized.

## Widgets

| Widget | Description |
| --- | --- |
| [`widgets/nutrislice`](widgets/nutrislice) | Today's school lunch menu from Nutrislice |
| [`widgets/mealviewer`](widgets/mealviewer) | Today's school lunch menu from MealViewer |

Both lunch widgets do the same job for different providers — check which one your
school district uses and set up that one. Each folder has its own setup notes.
